# Roadmap
## GENESIS-1
Create and review the theory, proposed architecture, scenarios, research questions and measurement protocol. Check all required files, commit on main, and attempt private GitHub publication. The initial environment record is an execution observation, not an architecture benchmark.

## Candidate future stages
GENESIS-2, only with a new instruction, could refine schemas and manually replay small tasks. A later prototype could implement a local evidence ledger and read-only discovery adapter. Controlled experiments should precede any orchestration or automated modification system.

Progression gates are explicit: agreed scope and privacy boundaries; reproducible acceptance tests; bounded recovery; measured overhead; evidence of usefulness across more than one hardware class. Production readiness would require separate reliability, access-control and operational evaluation.

## Deferred decisions
Storage technology, model provider, runtime, agent framework and scheduler remain open. Choosing them now would confuse theoretical requirements with implementation commitments.
