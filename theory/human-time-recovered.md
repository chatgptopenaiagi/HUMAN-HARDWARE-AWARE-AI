# Human time recovered
HUMAN_TIME_RECOVERED = BASELINE_HUMAN_TIME − AI_ASSISTED_HUMAN_TIME.

Use comparable tasks with the same acceptance criteria and outcome quality. Measure active human minutes for planning, setup, supervision, correction, review and recovery in both conditions. Record unattended elapsed time separately; faster machine execution is not automatically recovered human time.

## Study design
Use paired tasks or matched participants, counterbalance order and report experience, prior familiarity and tool availability. Freeze the baseline workflow before trials. Count failed and abandoned attempts under the same observation window.

Report paired differences and uncertainty, with participant and task variation. Negative values are possible. Do not value recovered time in money without explicit valuation assumptions; do not extrapolate from a small convenience sample to global savings.

## Limitation
The counterfactual baseline cannot be observed for the exact same person and task simultaneously. Learning, task variation and observer effects require controls. No time-recovery result has been measured in GENESIS-1.
