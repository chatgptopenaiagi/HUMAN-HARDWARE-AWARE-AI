# Unified system memory
## Evidence vocabulary
- **OBSERVED FACT:** a source reported something at a specified time; interpretation remains limited.
- **VERIFIED FACT:** a defined check passed for a claim in a stated scope and time.
- **HISTORICAL FACT:** retained past evidence whose present applicability has expired or is unknown.
- **HYPOTHESIS:** a falsifiable explanation or proposed relationship.
- **PREDICTION:** a forecast with horizon, assumptions and an eventual comparison.
- **UNKNOWN:** information absent, conflicting or insufficient.

These are operational labels, not absolute truth guarantees. Preserve the original evidence label and separately track freshness so an old verified record remains auditable as historical evidence.

## Coverage
Remember inventories, runtime versions, capability probes, installations, active tasks, completed and failed operations, objectives, project status, known problems, dependencies and experiment results. Store failure causes as hypotheses until supported.

## Rules
Append corrections and superseding evidence; do not erase inconvenient failures. Store references and redacted summaries instead of credentials. Conflicts become explicit unresolved records. See [persistent state](../architecture/persistent-state.md) for proposed fields.
